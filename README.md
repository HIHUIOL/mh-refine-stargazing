# 炼化观星记录

一个为《怪物猎人》玩家做的装备炼化观星辅助工具。  
纯前端、单文件、离线可用，支持 PWA 安装到手机主屏。

## 功能

- **自动计算停止金币**：告诉你金币降到多少就该停手
- **所在次数**：这件装备在整场观星中第几次出现
- **停手次数**：从上一件到这件需要炼几次后停手
- **炼化时长**：按每分钟炼化次数换算成时/分/秒
- **目标装备统计**：每件目标装备各记录了多少个
- **校准进度**：中途金币变了？标记当前进度，后续自动重算
- **分享 / 读取**：生成分享码，换设备不用重新录
- **本地保存**：数据自动存在浏览器，关页面不丢

## 使用说明

### 参数区

| 字段 | 说明 |
|------|------|
| 观星时金币 | 观星那一刻手里的金币，用来算所在次数 |
| 开炼时金币 | 实际开始炼化时的金币，留空则同观星时 |
| 每次炼化金币 | 游戏里单次炼化消耗的金币 |
| 每分钟炼化次数 | 你实际每分钟能炼几次 |

### 添加装备

填写「出技能时金币数」「技能名」「目标装备」，点击添加。  
技能名和目标装备可以留空。

### 校准

如果中途金币变了（做装备、卖素材等），点装备卡片上的 **📍**，填入当前实际金币数。  
校准后：

- 这件装备标记为「当前进度」
- 它之后的装备停止金币会按新金币重算
- 停手次数和所在次数不受影响，保持稳定

### 分享 / 读取

- **分享**：生成一段短分享码，复制发给别人或另一台设备
- **读取**：粘贴分享码，导入数据，覆盖当前记录

## 部署

### GitHub Pages

1. 新建仓库，建议命名 `mh-refine-stargazing`
2. 把以下文件放到仓库根目录：
index.html
manifest.json
sw.js
icons/
icon-192.png
icon-512.png

3. Settings → Pages → Source 选 `main` 分支 `/ (root)`
4. 访问 `https://你的用户名.github.io/mh-refine-stargazing/`

### 图标

需要准备两张 PNG 图标：

- `icons/icon-192.png`（192×192）
- `icons/icon-512.png`（512×512）

可以用游戏截图，也可以自己画一个。
